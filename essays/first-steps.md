It's been about three weeks since I started learning about software engineering, and somehow I feel like I've learned a lot and not that much all at the same time. I have definitely done many assignments to help me learn different things about software engineering, but these assignments and topics feel very similar to what I have learned in previous programming classes. This is probably because the main topic I have been studying has been the TypeScript programming language.

## What is TypeScript?

Typescript is a superset of JavaScript, which means that its basic syntax (grammar for a programming language)is the same as JavaScript, but it adds on extra syntax rules to have extra functionality. One of the main extra things it adds to JavaScript is that it allows you to specify the type of a variable, so you can concretely define a variable as a number, string, array, or something else, which is impossible to do in JavaScript. The main benefit to this is that other people will know what kind of data your variables are meant to be holding without having to guess based off of how it is used in the program.

## So Why Did TypeScript Feel So Similar?

With that brief definition of TypeScript aside, the main reason it all felt similar to me despite not having learned JavaScript or TypeScript before is because I have experience in the C/C++ programming language as well as limited experience in Python. As I was learning TypeScript, I realized that its syntax was very similar to C/C++ or at least had alternative syntax to make it similar to C/C++. Because of these many similarities, there were only a few things that were different from languages I had studied before, which thankfully made it relatively easy to learn and use throughout the many assignments I completed in the last few weeks. Personally, due to the ease of use, I feel like TypeScript will be useful to me as I learn more about software engineering.

## How Have You Been Learning Software Engineering?

While TypeScript felt similar and like I wasn't learning too much, the method of learning was definitely new. The software engineering class I am taking uses *athletic software engineering* as their main approach to learning. That term refers to the fact that it is very skill-based and less knowledge-based than classes I have taken before and is much more demanding, with as many assignments in the last three weeks as I would get in about five to six weeks in other classes. While this style of learning is quite new to me and somewhat stressful, I do believe I will learn a lot by the end of the course and hopefully have a project to show for it.
