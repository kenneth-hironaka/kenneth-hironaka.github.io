ConnectU was a project that utilized several different data structures to implement a text-based social network. This project was the main focus of ECE 367L, the lab component of the Data Structures and Algorithms course (ECE 367) at UH Manoa. In the beginning of the semester, we were given a basic program that just allowed you to login from a premade list of users which then showed a screen with over seven different features that were not yet implemented. Over six labs, these seven features were implemented using data structures like linked lists, priority queues, and binary search trees along with algorithms like breadth first search for things like viewing posts and finding recommendations for new friends based off of your current friends.

While this project was a daunting task at first, each lab broke it up into a digestible piece that made it seem more manageable to complete throughout the semester. It was a nice chance to actually test and use the different data structures and algorithms that we were learning about in the lecture portion of the class.
